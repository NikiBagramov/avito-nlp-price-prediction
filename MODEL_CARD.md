# Модели и применение

Основная цель - исследовать полезность русскоязычного текста для прогноза цены объявления. Итоговый метод выбирается по `dev_log_mae`, а не по test. Полный выбор записан в `artifacts/full/run_manifest.json`, отдельный выбор на малой подвыборке - в `artifacts/subset/run_manifest.json`.

Цель обучения CatBoost и Ridge - `log(price_RUB)`. В `predictions.csv` колонки методов содержат логарифмы, их следует экспоненцировать для рублей. Колонки `price` - исходные рубли. Метрики `median_ape` - доля, а не проценты. JSON не содержит скрытого перевода в баллы курса.

CatBoost: depth 6/8 по dev, learning_rate .04, до 1500 деревьев, early stopping 100 по RMSE на dev, seed 42, проверка seeds 43/44 у основных контролей. CatBoost использует 4 CPU-потока. Таблица базовых полей и расширение определены в `scripts/common.py`. Пропуски -1/[missing]. Точный адрес не подаётся.

Ridge: alpha 1/10/100 по dev. TF-IDF fit только на train. Residual-модели используют трёхкратный групповой cross-fitting табличного CatBoost. Базовая таблица обучается на всех train после получения OOF-остатков. В blend вес определяется по dev с шагом .05.

Qwen3-Embedding-0.6B, revision `97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3`: замороженные веса, float16 CUDA, 1024 нормализованных измерения, last-token pooling, left padding, 512 токенов. Не дообучалась на тестовых ценах.

Qwen3-1.7B, revision `70d244cc86ccca08cf5af4e1e306ecf908b1ad5e`: float16 CUDA, SDPA, thinking off, greedy. Вход до 1536 токенов; выход 256 для атрибутов и 32 для прямой цены. Метки unknown / unsupported / invalid различаются. Прямой ценовой fallback - медиана цены train, частота ошибки отдельно фиксируется. Предобученные веса двух моделей Apache-2.0.

Все локальные сырые ответы сохранены для аудита; они исключены из публичного пакета из-за объёма исходных описаний. Метрики, split IDs, параметры и хэши включаются. Коммерческих API в этом запуске нет.

Не предназначено для решений о доступе к жилью/кредиту, для определения мошенничества или определения справедливой цены сделки. Один городской срез, рекламные преувеличения, неполные признаки, дорогой хвост, шумные географические поля и остаточные повторы ограничивают переносимость. SHAP описывает модель, а не причинность.
