# Единый журнал проверки

## 2026-11-13

- Область: самостоятельный учебный NLP-проект; Backend/Frontend Atraxis не изменяются.
- Требования: структура отчёта Overleaf; исходный код; данные с происхождением; воспроизводимые сравнения; реальные результаты; ограничения и анализ ошибок.
- Известные ограничения: согласование темы преподавателем и выставление баллов не выполнены и не могут подменяться экспериментальными результатами. Опубликованного рекорда на точной выборке пока не установлено.
- Нельзя называть сгенерированные моделью метки ручной эталонной разметкой. Цены объявлений не являются ценами сделок. SHAP/важности не доказывают причинность.
- Проверки и результаты будут добавляться по мере фактического выполнения.

## Выполнено

- Данные скачаны с официального публичного Kaggle API. Проверены SHA-256 архива и трёх исходных файлов. Исходные скрипты автора не выполнялись.
- Аудит XLSX: 32 967 строк, 51 поле, 1 915 повторных ID до фильтра. После проверок и дедупликации 30 775 строк, 8 610 адресно-шаблонных компонент; splits 21 718 / 4 582 / 4 475.
- Реально выполнены GPU-прогоны Qwen3-Embedding-0.6B для всех 30 775 текстов, две версии Qwen3-1.7B извлечения для 2 100 текстов каждая и 1 400 прямых ценовых запросов. Веса закреплены revisions. Сохранены сырые локальные ответы, маски допуска и журналы времени; они не публикуются вместе с полными объявлениями.
- Обучены и сравнены 11 методов на полной выборке и 14 на одинаковой малой подвыборке. Итоговый выбор по dev: rich_embedding_residual, test log MAE ~0.1551, MdAPE ~12.14%, MAE ~3.803 млн RUB. Его bootstrap CI разности с расширенной таблицей включает ноль. Для rich_tfidf_residual интервал целиком отрицателен; анализ исследовательский, с ограничениями выбора и множественных сравнений.
- Проведены групповой парный bootstrap 1000 повторов, четыре абляции, SHAP на 512 test наблюдениях, срезы по цене/району, разбор крупных ошибок и диагностика извлечения. Ручной gold не выдумывался.
- `verify_results.py` пересчитал все test-метрики из выпущенных CSV, проверил конечность всех предсказаний и эмбеддингов, норму эмбеддингов и полный состав ID двух LLM-кэшей. Устранено микроскопическое различие float32/CSV: вычисления метрик приведены к float64, итоговые test-числа пересчитываются из опубликованного CSV. Выбор по dev не менялся.
- 7 unittest-проверок прошли: удаление цены с сохранением площади/года, омоглифы/шаблоны, транзитивные группы, отказ неподтверждённой цитате, изоляция split, обучение few-shot примеров только в train и единицы метрик.
- Ноутбук `project.ipynb` валидирован nbformat; его ячейки не представлены как выполненные. Все реальные прогоны делались CLI-этапами. Отдельная свежая Colab-среда не проверялась.
- После завершения всех этапов успешно выполнен единый `run_pipeline.py --skip-download --skip-generation-download --no-report` с готовыми данными/весами. Он подтвердил корректность повторного запуска из кэша, пересчёта сравнений, проверок и сохранения исходных журналов времени. PDF собирался отдельно тем же builder через bundled Python с reportlab.
- PDF содержит все части шаблона курса, 10 непустых страниц; проверены извлекаемый текст и имена. Все страницы просмотрены после рендеринга; после правок интервалов и заключения дополнительно просмотрены изменённые страницы 5, 9 и 10. Перекрытий/обрезки/пропавших глифов не обнаружено.
- Дополнительная форма разметки: проверены синтаксис JS и схема слепой выборки из 100 test ID. Визуальный браузерный smoke не завершён: IAB не получил доступ к localhost. Временный локальный сервер остановлен. Форма необязательна для основной регрессионной задачи; человеческая разметка пока отсутствует.
- Пакет исходников исключает данные, адреса, полные тексты/ответы, веса, модели, кэши, временные рендеры, `.git` и частный план баллов `COURSE_SUBMISSION.md`. Архив проверяется `ZipFile.testzip()`.
