# Независимая ручная проверка (дополнительный этап)

Сейчас в отчёте **нет ручного gold**. Этот инструмент подготовлен для настоящей независимой проверки авторами и не выдаёт машинные ответы за человеческую разметку. Основная задача регрессии использует исходные цены и не зависит от заполнения этого дополнения.

Запустите `python scripts/prepare_review.py`, откройте `annotation/index.html` браузером и выберите `data/annotations/review_100.json`. Цена, исходная категория ремонта и ответы моделей скрыты. Впишите своё имя. Для каждого из пяти признаков выберите значение и скопируйте точную цитату. «Не указано» отличается от явно отрицательного ответа. При противоречии, условии («по договорённости оставим») или описании общих возможностей ЖК лучше оставить unknown и зафиксировать вопрос отдельно.

Никита и Альфия заполняют выборку **независимо**, не сверяясь с моделью или друг с другом. Каждый скачивает свой JSON. После этого нужно посчитать согласие, разобрать расхождения и сформировать согласованный файл. Автоматический поиск цитаты проверяет опору на текст, но не смысл разметки. Не ставьте метку «нет обременений» только из одного собственника; не ставьте «вид на воду» из близости реки.

В интерфейсе ответы сохраняются только в текущем сеансе. Регулярно скачивайте JSON, чтобы не потерять работу. Чтобы продолжить, загрузите сначала выборку, затем свой JSON. Не переименовывайте незаполненную или автоматически заполненную выборку в human gold. Добавление ручных метрик в отчёт возможно только после фактической проверки.

Сотня примеров - ограниченный аудит, а не доказательство высокой точности на всех объявлениях. Для полноценного набора 500-800 примеров потребуются дополнительный независимый подбор, труд разметчиков, анализ согласия и фиксирование финального test до настройки модели.
